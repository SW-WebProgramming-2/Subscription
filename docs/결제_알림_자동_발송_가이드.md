# 결제 알림 자동 발송 기능 가이드

## 📋 기능 설명

결제일 하루 전에 자동으로 사용자에게 이메일 알림을 보내는 기능입니다.

## 🚀 사용 방법

### 1. 자동 실행 (Vercel 배포 시)

Vercel에 배포하면 `vercel.json` 파일에 설정된 대로 **매일 오전 9시**에 자동으로 실행됩니다.

```json
{
  "crons": [
    {
      "path": "/api/notifications/send-payment-reminders",
      "schedule": "0 9 * * *"
    }
  ]
}
```

### 2. 수동 실행 (관리자)

1. 관리자 계정으로 로그인
2. 프로필 페이지로 이동
3. "📧 결제 알림 수동 발송" 버튼 클릭
4. 확인 후 발송 완료

### 3. API 직접 호출

#### GET 요청 (외부 스케줄러 사용 시)
```bash
# API 키가 설정된 경우
curl https://your-domain.com/api/notifications/send-payment-reminders?key=YOUR_API_KEY

# API 키가 없는 경우 (로컬 개발)
curl http://localhost:3000/api/notifications/send-payment-reminders
```

#### POST 요청 (관리자 인증 필요)
```bash
curl -X POST https://your-domain.com/api/notifications/send-payment-reminders \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json"
```

## ⚙️ 설정 방법

### 1. 환경 변수 설정

`.env.local` 파일에 이메일 발송 설정이 필요합니다:

```env
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-app-password

# 선택사항: API 키 설정 (외부 호출 보안)
CRON_API_KEY=your-secret-key
```

### 2. Vercel Cron 설정 (선택사항)

로컬 개발 환경에서는 자동 실행되지 않습니다. Vercel에 배포하면 자동으로 실행됩니다.

## 📧 이메일 내용

발송되는 이메일에는 다음 정보가 포함됩니다:
- 구독 서비스명
- 결제 예정일 (한글 형식)
- 결제 금액
- 결제 주기
- 안내 메시지

## 🔍 동작 원리

1. 모든 구독 서비스를 조회
2. 각 구독의 다음 결제일을 계산
3. 결제일이 **내일**인 구독을 찾음
4. 해당 구독의 사용자에게 이메일 발송
5. 발송 결과 반환

## 🐛 문제 해결

### 알림이 발송되지 않는 경우

1. **구독 서비스가 있는지 확인**
   - 구독 서비스가 등록되어 있어야 합니다

2. **결제일 계산 확인**
   - 구독 서비스의 `createdAt` 날짜를 기준으로 계산됩니다
   - `billingCycle`이 올바르게 설정되어 있는지 확인

3. **이메일 설정 확인**
   - `.env.local` 파일의 SMTP 설정이 올바른지 확인
   - Gmail 사용 시 앱 비밀번호를 사용했는지 확인

4. **사용자 이메일 확인**
   - 사용자 정보에 이메일이 등록되어 있는지 확인

### 로컬에서 테스트하는 방법

1. 구독 서비스를 추가할 때 `createdAt`을 조정하여 내일이 결제일이 되도록 설정
2. 관리자 계정으로 로그인
3. 프로필 페이지에서 "결제 알림 수동 발송" 버튼 클릭
4. 결과 확인

## 🔒 보안

- GET 요청: API 키로 보호 (선택사항)
- POST 요청: 관리자 인증 토큰 필요
- 이메일 발송 실패 시 에러 로그만 기록 (민감 정보 노출 없음)

## 📝 참고사항

- 같은 구독에 대해 하루에 여러 번 발송되지 않습니다
- 결제일이 정확히 하루 전인 경우에만 발송됩니다
- 이메일 발송 실패 시 에러 정보가 응답에 포함됩니다
